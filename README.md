# Deepak Sai Cherukuri — Portfolio

A personal portfolio based on [aahil-khan/portfolio-canvas](https://github.com/aahil-khan/portfolio-canvas), personalized with my résumé, projects, skills, and contact details.

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## GitHub Pages

The `codex/deepak-portfolio-update` branch has a GitHub Actions workflow that exports the public
portfolio to static files and publishes them to the repository's existing `gh-pages` branch. The
site is at `https://cherukurideepak-sai.github.io/3d-portfolio/`. The static site includes the
homepage and project pages; server-backed editing, analytics, and API features remain available
only when running the app with a server.

## Content

Portfolio content lives in `content/data/`. Project screenshots and a profile photo can be added when available. Social profile links can be added when provided.
